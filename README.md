# Genshin DPS Archive

A fan-made theorycrafting archive for Genshin Impact character rankings, combat baselines, and account-aware pull-value guidance.

## Live website

https://genshin-tier-list-eight.vercel.app/

## Native Android app

The native Kotlin + Jetpack Compose app now has its own repository:
https://github.com/Thunder2700c/Genshin-DPS-Archive-Android

Android app code and build workflows are maintained separately so website deployments stay focused on the static site.

## Website structure

- `index.html`: main page
- `tiers/`: tier ranking pages
- `characters/`: character detail pages
- `assets/images/`: site images
- `css/` and `js/`: site styling and behaviour
